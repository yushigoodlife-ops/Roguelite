# 第1週：プロのゲーム開発スタート！「プロジェクト作成と魔法のセーブ機能」

## 本日の目標
いよいよ今日から、プロのゲームクリエイターへの第一歩を踏み出します！
まずはゲームを作るための「作業机」を用意し、プロが必ず使っている「魔法のセーブ機能（Git）」を導入しましょう。

1. **作業机の用意（Unity）**：新しい3Dプロジェクトを作成する。
2. **舞台の準備（Scene）**：ゲームの土台となる3つの画面（タイトル、メイン、リザルト）を作る。
3. **魔法のタイムマシン（GitHub & SourceTree）**：絶対にデータが消えず、いつでも過去に戻れる最強のバックアップシステムを導入する。

---

## 1. 魔法のタイムマシン（Git）を準備しよう！

ゲームを作っていると「昨日は動いたのに、今日いじったら壊れた！元に戻せない！」という絶望的な瞬間が必ず来ます。
プロの現場では、これを防ぐために **「Git（ギット）」** というバージョン管理システム（タイムマシン）を使います。

まずは、クラウド上（GitHub）にあなたのゲーム専用の金庫（リポジトリ）を作りましょう。

### 💡 エディタでの作業手順（GitHubで金庫を作る）
- [ ] ブラウザで **GitHub** にログインし、画面右上の `+` ボタンから `New repository` をクリックする。
- [ ] `Repository name` に **TPSRoguelite** と入力する（これがゲームの名前になります）。
- [ ] `Public`（公開）か `Private`（非公開）を選ぶ（通常はPrivateでOK）。
- [ ] **【超重要】** `Add .gitignore` のチェックを入れ、右の枠で **Unity** と検索して選択する。
  *※これを忘れると、不要なゴミファイルが大量に保存されて金庫がパンクします！*
- [ ] 一番下の `Create repository` ボタンを押す。

### 💡 エディタでの作業手順（SourceTreeでパソコンに持ってくる）
次に、今作ったクラウドの金庫を、自分のパソコンと繋ぎます（これを「クローン」と呼びます）。

- [ ] GitHubの画面にある緑色の `<> Code` ボタンを押し、表示されたURLをコピーする。
- [ ] **SourceTree** を開き、`Clone`（または「クローン/新規作成」）をクリックする。
- [ ] 「元のパス/URL」に、さっきコピーしたURLを貼り付ける。
- [ ] 「保存先のパス」を、自分の分かりやすい場所（ドキュメントフォルダなど）に設定する。
- [ ] `クローン` ボタンを押す！これであなたのパソコンに「TPSRoguelite」という空のフォルダができました！

---

## 2. 作業机の用意（Unityプロジェクトの作成）

SourceTreeで作ったフォルダの中に、いよいよUnityのプロジェクトを作成します！

### 💡 エディタでの作業手順
- [ ] **Unity Hub** を起動し、右上の `新しいプロジェクト (New Project)` をクリックする。
- [ ] テンプレートから **`3D (Core)`** を選択する。
- [ ] プロジェクト名（Project Name）を **TPSRoguelite** にする。
- [ ] **【超重要】** 保存先（Location）の右にあるフォルダアイコンをクリックし、**先ほどSourceTreeでクローンしたフォルダの中**を指定する。
- [ ] `プロジェクトを作成 (Create project)` を押して、Unityが開くまで待つ（少し時間がかかります）。

---

## 3. ゲームの土台となる「3つの舞台」を作ろう！

Unityが開きました！
ゲームは通常、「タイトル画面」「遊ぶ画面」「結果発表画面」という複数のシーン（Scene）で構成されます。今日はこの3つの空箱を用意して、ゲームの枠組みを完成させます。

### 💡 エディタでの作業手順（シーンの作成）
- [ ] Unity画面下の `Project` ウィンドウから、`Assets > Scenes` フォルダを開く。
- [ ] 最初からある `SampleScene` をクリックして選び、名前を **`MainGameScene`** に変更する。（※警告が出たら `Reload` または `Yes` を押す）
- [ ] `Scenes` フォルダの何もない所で右クリックし、`Create > Scene` を選ぶ。
- [ ] 作ったシーンの名前を **`TitleScene`** にする。
- [ ] 同じようにもう一つ `Create > Scene` を作り、名前を **`ResultScene`** にする。

### 💡 エディタでの作業手順（Build Settingsへの登録）
作ったシーンは、Unityのシステムに「このゲームにはこの3つの画面がありますよ」と登録しないと使えません。

- [ ] 画面上のメニューから `File > Build Settings...` をクリックして開く。
- [ ] `Project` ウィンドウにある `TitleScene` をドラッグし、Build Settingsの **`Scenes In Build`** の枠の中にドロップする。
- [ ] 同じように `MainGameScene` と `ResultScene` もドラッグ＆ドロップして追加する。
- [ ] 枠の中に3つのシーンが並べばOK！設定画面を閉じる（×ボタン）。

---

## 4. 今日の成果をセーブ（コミット＆プッシュ）しよう！

お疲れ様でした！最後に、今日作ったシーンやプロジェクトの状態を、魔法のタイムマシン（Git）にセーブして終わりましょう。

### 💡 エディタでの作業手順
- [ ] **SourceTree** の画面を開く。
- [ ] 「ファイルステータス」の画面を見ると、Unityで作ったファイルが大量に表示されているはずです。
- [ ] 左上の **`すべてインデックスに追加 (Stage All)`** ボタンを押す。（ファイルが上の枠に移動します）
- [ ] 画面下のメッセージ欄（コミットメッセージ）に **「第1週：プロジェクトと3つのシーンを作成」** と、何をしたか分かりやすく書く。
- [ ] 右下の **`コミット (Commit)`** ボタンを押す！（これでパソコンの中へのセーブが完了）
- [ ] 最後に、画面上の **`プッシュ (Push)`** ボタンを押し、OKを押す。（これでクラウド上の金庫へのバックアップが完了！）

**これで第1週は完了です！ 次回からは、このプロジェクトにキャラクターや武器を追加して、実際にゲームを動かしていきます。お楽しみに！**
